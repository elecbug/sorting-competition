SUBMISSION GUIDE

CSV는 준비되어 있습니다.

다음 구조를 그대로 사용합니다. csv_sort.h를 포함하고, student_sort 함수만 작성하세요. CSV 파싱과 결과 검증은 채점기가 수행합니다.

typedef struct {
    char *text;
} string;

typedef struct {
    string *data;
    size_t count;     // 열 개수
} row;

typedef struct {
    row header;       // CSV 첫 번째 행
    row *rows;        // 데이터 행
    size_t count;     // 헤더 제외 행 개수
} rows;

void student_sort(rows *table);

각 셀은 UTF-8 문자열입니다. 정렬 기준은 문제 설명에 따릅니다. 헤더, 행 개수, 셀 내용을 보존하고, table->rows의 순서를 바꾸세요. 열 번호는 C에서 0부터 시작합니다.

결과는 교수자의 정답 CSV와 셀 내용 및 행 순서까지 정확히 비교합니다. 같은 키의 행은 문제의 동률 규칙을 따라야 합니다. main()이나 표준 출력 코드는 작성하지 마세요. 지역 파일·네트워크 접근과 추가 프로세스 생성은 제한됩니다.
