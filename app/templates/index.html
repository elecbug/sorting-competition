typedef struct { char *text; } string;

typedef struct {
    string *data;
    size_t count;  // columns
} row;

typedef struct {
    row header;
    row *rows;
    size_t count;  // data rows, excluding header
} rows;

void student_sort(rows *table);

Sort table->rows according to the problem. Preserve the header, row count, and cell contents. Cells are UTF-8 strings. C column indices start at 0.

Cell contents and row order must match the answer exactly, including rows with equal keys. Do not write main() or print output.
